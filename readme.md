# 📝 Command-line Todo List App

A simple Python-based **command-line Todo List application** that lets you add, list, and remove tasks using a text file (`tasks.txt`) as storage.

---

## 🚀 Features
- ➕ Add new tasks
- 📋 List all tasks
- ❌ Remove tasks by index
- 🗂️ Persists tasks in `tasks.txt`

---

## 📦 Requirements
- Python 3.x

No external dependencies are required — this app uses only Python’s standard library.

---

Run the script with the available options:
